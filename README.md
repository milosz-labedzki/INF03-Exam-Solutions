## About

Worked solutions for the INF.03 practical exam (*Tworzenie i administrowanie stronami i aplikacjami internetowymi*), covering sessions from 2022 to 2026. Each solution follows the official CKE exam brief and is implemented as a fully functional web application.

---

## Topics Covered

* **Frontend:** HTML5 (semantic markup), CSS3 (Flexbox, Grid, form styling), JavaScript (vanilla DOM manipulation, event handling, simple validation).
* **Backend:** PHP (form handling, MySQLi/PDO integration, session management, input sanitization).
* **Database:** MySQL/MariaDB (relational schema design, SELECT/INSERT/UPDATE queries, joins).
