## 📌 About

This repository collects my worked solutions for the **INF.03** practical exam (Polish IT vocational qualification: *Tworzenie i administrowanie stronami i aplikacjami internetowymi*), covering past sessions from 2022 to 2026. Each solution is built from the official exam brief and implemented as a working web application.

---

## 🗂️ Structure

```
INF03-Exam-Solutions/
├── inf03_YYYY_MM_DD/     # One folder per exam session
│   ├── *.html / *.php     # Frontend & server-side files for the task
│   ├── *.css               # Styling
│   ├── *.sql / *.txt       # Database schema and/or query notes
│   └── *.jpg                # Task-specific assets (mockups, screenshots, etc.)
└── README.md
```

Folders are named after the exam session date (`YYYY_MM_DD`). File names inside each folder vary session to session, since every exam task specifies its own requirements — new sessions just get added as their own folder, no changes needed here.
